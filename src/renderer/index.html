Settings

A few practical preferences for your downloads.

Download location

New downloads are saved to this folder.

Simultaneous downloads

Keep this low if your connection or file host limits transfers.

Connections per file

Use several connections for each large file. Ravenshelf falls back to one when needed. Changes apply when a file starts or resumes; partial files from older versions keep one connection.

Scan finished downloads

Ask Microsoft Defender to scan each file when it finishes and show the result on its card. If Defender finds a threat it may quarantine the file. Scans run one at a time.

Clear about what’s checked

Link checks confirm availability. Microsoft Defender scans help, but no scan can prove a file is safe.

Some hosts require a browser challenge or a manual step. Ravenshelf opens supported hosts in a separate protected window that blocks pop-up windows and off-site navigation. These restrictions can prevent some host pages from working.

You can also copy or export the complete link set, or send it to JDownloader when it is running. Protection against pop-ups does not guarantee that a host or its files are safe.

Downloads never run automatically. Review the files and installation instructions before opening an installer.

Shared download speed

Keep some bandwidth free for other apps. This limit is shared across all active files and connections.

0 means unlimited.

Download hours

Use your laptop’s local time. Outside this window, scheduled downloads wait until the next allowed period.

Days

An end time earlier than the start continues into the next day. Matching times allow the whole selected day.

Small conveniences

Get completion and problem notices while Ravenshelf is open.

File integrity
