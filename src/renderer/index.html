Settings

A few practical preferences for your downloads.

Download location

New downloads are saved to this folder.

Loading…

Simultaneous downloads

Keep this low if your connection or file host limits transfers.

Connections per file

Use several connections for each large file. Ravenshelf falls back to one when needed. Changes apply when a file starts or resumes; partial files from older versions keep one connection.

Scan finished downloads

Ask Microsoft Defender to scan each file when it finishes and show the result on its card. If Defender finds a threat it may quarantine the file. Scans run one at a time.

Browser extension

Send downloads from Chrome, Edge, Brave or Firefox to Ravenshelf. Each one is checked before anything is saved, and the extension blocks dangerous sites and the pop-ups and redirects of file-host pages.

Chrome, Edge or Brave

  1. Choose Open folder to see the extension Ravenshelf prepared.
  2. In the browser, open chrome://extensions and turn on Developer mode.
  3. Choose Load unpacked and select that folder.

Firefox

  1. Choose Open folder.
  2. In Firefox, open about:debugging#/runtime/this-firefox.
  3. Choose Load Temporary Add-on… and pick manifest.json in that folder. Firefox removes temporary add-ons when it closes.

Protection lists

Where the lists come from

    Ravenshelf downloads each list whole and checks addresses on this PC; it never asks a list provider about the sites you visit.

    VirusTotal (optional)

    With your own free VirusTotal API key, Ravenshelf also looks up the sites each browser download comes from, and the SHA-256 fingerprint of each finished browser download. Only site names and fingerprints are sent, never your files or full web addresses. Free keys allow 4 lookups a minute and 500 a day, and VirusTotal’s terms apply.

    YouTube downloads

    Download a YouTube video with the Ravenshelf button in YouTube’s player, or right-click a video and choose Download with Ravenshelf. This uses the browser extension above.

    The button in YouTube’s player lets you choose each time.

      Only download videos you own, that use a Creative Commons licence, or that you have permission to save. YouTube’s terms allow downloading only where YouTube offers it or with permission. Ravenshelf never uses your YouTube sign-in or browser cookies.

      Clear about what’s checked

      Link checks confirm availability. Microsoft Defender scans help, but no scan can prove a file is safe.

      Some hosts require a browser challenge or a manual step. Ravenshelf opens supported hosts in a separate protected window that blocks pop-up windows and off-site navigation. These restrictions can prevent some host pages from working.

      You can also copy or export the complete link set, or send it to JDownloader when it is running. Protection against pop-ups does not guarantee that a host or its files are safe.

      Downloads never run automatically. Review the files and installation instructions before opening an installer.

      Shared download speed

      Keep some bandwidth free for other apps. This limit is shared across all active files and connections.

      0 means unlimited.

      Download hours

      Use your laptop’s local time. Outside this window, scheduled downloads wait until the next allowed period.

      Days

      An end time earlier than the start continues into the next day. Matching times allow the whole selected day.

      Small conveniences

      Get completion, problem and update notices while Ravenshelf is open.

      Opt in to recognize supported links you copy. Review them in Copied links; downloads never start from the clipboard automatically.

      Use colors from the cover you open, with a readable fallback.

      File integrity

      Manually compare your downloaded files against a checksum manifest. Choose the manifest and folder yourself.

      Ravenshelf updates

      Checking update availability…

      Ravenshelf downloads an update only after you choose Download and install. It first checks that GitHub’s signed build record names that exact file and comes from Ravenshelf’s release workflow. A verified update installs when you close Ravenshelf; Restart now waits until downloads, scans and verification are idle.
