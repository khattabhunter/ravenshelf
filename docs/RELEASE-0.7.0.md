# Ravenshelf 0.7.0 — PC specs, and Nexus Mods downloads filed by game

Ravenshelf can now show what is inside your PC, and it files the mods you download on Nexus Mods by game. Settings, collections, the queue and downloads stay where they are.

- **PC specs:** a new page shows the processor, each graphics adapter with its real graphics memory (also above 4 GB), which adapter games use, DirectX support, memory installed and usable, drives with their type and free space, the display and the Windows version. Ravenshelf asks Windows when you open the page, in about a second.
- **Nothing leaves your PC:** the hardware check is a fixed, read-only script that asks Windows only for model names, sizes and capability levels. It never asks for serial numbers, the computer's name, user names, volume labels or network addresses. The answer stays in memory: it is not saved, not sent to any site and not shared with the browser extension.
- **Only what is certain:** when Windows gives no trustworthy figure, the page says **Not reported by Windows** instead of guessing, and a graphics card with a missing or broken driver says so.
- **Nexus Mods downloads filed by game:** with the browser extension connected, a file you download on Nexus Mods is recognised. The review shows the mod, the game and the folder, and **Download** saves it in `Mods\<game>` in your download folder, for example `Mods\Skyrim Special Edition`. The toolbar button's **Sort Nexus Mods files by game** switch turns this off.
- **By Nexus Mods' rules:** mod files download over one connection, the site's waiting time and sign-in are untouched, and Ravenshelf uses no Nexus Mods account, API key or browser cookie. On Nexus Mods the extension only reads which game, mod and file the open page is about; that stays in your browser unless you download a file from Nexus Mods. Only files from Nexus Mods' own file servers count as mod files.

**Updating from 0.6.1:** open **Settings → Ravenshelf updates** and choose **Download and install**. Then choose **Reload** for Ravenshelf on your browser's extensions page and reload open Nexus Mods and YouTube tabs. The extension now also runs on www.nexusmods.com, so your browser lists that site next to www.youtube.com in the extension's details.

**Rules and limits:** Ravenshelf downloads mod files; it does not install them or check them against your games. **Mod manager download** buttons and Nexus Mods' own **Resumable download** are not handled. Nexus Mods' download links expire. A mod download that fails for that reason says so; start it again from the mod's page and the failed entry carries on with the new link. Only download mods you are allowed to use. **PC specs** shows what Windows reports and does not yet compare your PC with a game's requirements.

Download **Ravenshelf-0.7.0-Windows.exe** and compare its SHA-256 with **SHA256SUMS.txt**, or verify its build record with the GitHub CLI as described in the README. The portable executable remains unsigned: the build record shows where the file was built, but it is not Windows publisher signing or a malware verdict. Keep Windows protections enabled.
